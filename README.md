# Shopizer Research Findings

[Shopizer](https://github.com/shopizer-ecommerce/shopizer) open-source
e-commerce platform (backend 3.2.7, React storefront 3.0.0, Angular admin).

- **Start with [`SHOPIZER-BRIEFING.md`](SHOPIZER-BRIEFING.md)** — the condensed
  five-part briefing (overview, architecture, end-to-end flows,
  strengths/limitations, team onboarding).
- **`docs/`** — the full write-up, one document per section plus an index.

Surveyed from source: `shopizer/shopizer` (Spring Boot backend),
`shopizer/shopizer-shop-reactjs` (React storefront),
`shopizer/shopizer-admin` (Angular admin console).
